# 📼 RawMaster — Brickwall Limiter & Loudness Maximizer

> **Parte da Suíte Emo Audio Tools — [Underground Tools](https://github.com/FelipeGardenghiDev/underground-tools)**  
> *Limitador de pico real (True-Peak) com lookahead e medidor integrado de LUFS para masterização de streaming e CD.*

---

## 🎛️ Controles

* **Target Preset:**
  - `Streaming`: -14.0 LUFS (Spotify, Apple Music, YouTube)
  - `Loud CD`: -9.0 LUFS (Som de CD encorpado / Bandcamp)
  - `Raw Wall`: -7.0 LUFS (Paredão para Post-Hardcore / Screamo)
* **Ceiling:** Teto travado a -0.3 dB True Peak para evitar distorção interamostral em conversão MP3.
* **LUFS Live Meter:** Medidor em tempo real do nível de intensidade sonoramente ponderada.
